# Toggle

An Aqua-style capsule whose knob is a LiquidBubble.

## Anatomy
`toggle` (38×22 well; accent flood when on) → `knob` (16px, slides 16px) → `LiquidBubble` (platinum off, accent on, fill 0.5 → 0.72).

## Tokens
`--lp-platinum-4/-5`, `--lp-accent-base/-deep`, `--lp-shadow-emboss-well`, `--lp-motion-normal`, `--lp-motion-ease-spring`.
