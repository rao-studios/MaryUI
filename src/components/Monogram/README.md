# Monogram

The Rao mark: a serif R and its mirror sharing a stem.

## Variants
- `flat` — `currentColor`, for the menu bar (16–20px).
- `platinum` — platinum gradient fill + brushed `<pattern>` (overlay) + specular band + drop shadow, for hero use (120–240px).

## Notes
The symbol currently uses `<text>` in `--lp-font-display`; trace it to `<path>` (Sketch: Layer › Convert to Outlines) so metrics stop depending on installed fonts.
