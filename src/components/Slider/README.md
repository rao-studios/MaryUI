# Slider

A native range input dressed as an inset rail with a platinum thumb.

## Anatomy
`label` · `input[type=range]` (rail 5px: accent to `--lp-slider-pct`, then `--lp-platinum-4`; thumb 16px radial platinum) · `value` (mono, optional).

## Tokens
`--lp-accent-base`, `--lp-platinum-0/-3/-4/-5`, `--lp-shadow-emboss-*`, `--lp-edge-hairline`, `--lp-font-mono`, `--lp-text-xs/sm`.
