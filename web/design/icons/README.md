# design/icons/

Generated by `npm run icons` — do not hand-edit; edit `src/components/Icon/icons.json`,
`src/components/ObjectIcon/objects.json` or the `object` group in `tokens/tokens.json`.

- `glyph/` — 81 control marks, 24 grid, stroked at 1.7px
- `object/` — 69 lit objects, 32 grid

Drag one into Sketch and its importer converts it to editable vectors. Every layer is named after
the token its colour came from (`back · folder/top`, `keyline · edge/hairline`), so the shapes can
be re-bound to the Color Variables `liquid-platinum.sketch` already ships.

Two passes are deliberately absent. The **brushed grain** would import as a rasterised noise fill
rather than the pattern Sketch should apply itself, and the **contact shadow** belongs on the layer
as a real Sketch shadow. Apply both in Sketch; the Icons artboard in `liquid-platinum.sketch` shows
what they look like in the running app.
