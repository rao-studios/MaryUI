# ProgressBar

An inset rail with a liquid accent fill. Omit `value` for Aqua's barber pole, in platinum.

## Anatomy
`rail` (8px well) → `fill` (accent gradient, width `--lp-progress`) → `fill::after` (a travelling glint).

## Tokens
`--lp-platinum-1/-4`, `--lp-accent-*`, `--lp-shadow-emboss-well`, `--lp-radius-pill`, `--lp-motion-normal`.
