# MenuItem

One row: check column (18px), label, shortcut. `MenuSeparator` draws the hairline.

## States
default · active (accent gradient, on-accent ink) · checked · disabled (`--lp-ink-disabled`).

## Tokens
`--lp-size-control-height`, `--lp-radius-xs`, `--lp-accent-light`, `--lp-accent-base`, `--lp-ink-*`, `--lp-edge-divider`.
